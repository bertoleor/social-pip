## Cómo usar el Vault

1. **Buscar por nombre:**
   ```bash
   grep "keyword" skills/99-VAULT/INDEX.md
   ```

2. **Consultar una skill específica:**
   ```bash
   cat skills/99-VAULT/antigravity/skills/{skill-name}/SKILL.md
   ```

3. **Cargar manualmente en una sesión:**
   Pide al agente que lea la skill específica antes de trabajar en el tema.
